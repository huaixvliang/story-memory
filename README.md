# 剧情记忆核心（Story MemoryCore）

一个**通用于任意世界书 / 角色卡 / 题材**的 SillyTavern 扩展：把「剧情记忆」搬出 AI 的大脑存进本地，并在每次生成前智能注入回上下文。解决长对话里的数值丢失、前后文对不上、多线切换错乱。

> 本扩展由 [ntr-memory](https://github.com/huaixvliang/ntr-memory)（鸠占鹊巢·记忆核心）**通用化 + 优化**而来：
> - **优化**：修掉总结队列卡死、待总结消息无限增长、去重表误清空、斜杠命令取参错误、世界书读取旧值、总结失败丢消息、刷新后重复总结旧消息等缺陷；
> - **通用化**：不再写死角色名单 / 数值字段 / 苦主映射 / NTR 专属提示词。改为**自动识别角色与数值字段**，任何世界书装上就能用（修仙 / 西幻 / 现代 / NTR……）。
> - **角色卡记忆隔离**：每个角色卡 / 群聊各自独立一份记忆，进入哪张卡就自动切换成那张卡的记忆，互不串戏。
> - 老用户升级：首次运行会自动把旧的 ntr-memory 记忆数据无缝迁移过来。

## 手动安装（推荐，最简单）

把**本目录**（`story-memory/`，含 `manifest.json`、`index.js`、`style.css`、`README.md`）整个复制到：

```
SillyTavern/public/scripts/extensions/story-memory/
```

刷新酒馆（Ctrl+F5 或手机下拉刷新），进 Extensions 设置区看到 **「剧情记忆核心 · Story MemoryCore」** 面板即成功。

## 一键安装（Install Extension，需要先把本目录推到你的仓库）

酒馆的 Install Extension 走的是 `git clone`。如果你想用「拼图图标 → Install Extension → 粘贴地址」的方式：

1. 把本 `story-memory/` 目录推到**你自己的** GitHub 仓库（原仓库地址 `https://github.com/huaixvliang/ntr-memory` 里仍是旧版 ntr-memory，不含本通用版）；
2. 酒馆 → Extensions → Install Extension → 粘贴你的仓库地址 → Install；
3. 刷新页面。

### 更新 / 重装（重要）

Install Extension 用 `git clone`，**同一个目录第二次安装会报「Directory already exists」冲突**，不会自动更新。要更新：

1. 先删掉旧扩展：Extensions 列表里找到旧扩展 → 删除（Delete）；
   - 若删除后仍提示目录占用，手动删掉 `SillyTavern/public/scripts/extensions/third-party/...` 下对应文件夹；
2. 再重新 Install Extension 粘贴地址 → Install → 刷新。

或者手动更新更快：用最新 `index.js` + `manifest.json` + `style.css` 直接覆盖旧文件，再刷新。

## 功能

| 功能 | 说明 |
| --- | --- |
| **角色卡记忆隔离** | 每个角色卡 / 群聊各自独立一份记忆，进入哪张卡自动切到哪张卡的记忆，互不串戏 |
| 自动总结 | 攒满约 N 轮（默认 5）用主 API 提取「标签/人物/数值/时间/地点/事件/主线」 |
| 自动识别角色 | 无需手动配置：自动从对话参与者、当前卡片、群成员识别角色；也支持手动钉住名单 |
| 自动识别数值字段 | 默认自动追踪正文里出现的所有数值状态（好感/等级/HP/亲密度……）；也可手动指定字段 |
| 玩家面板追踪 | 连玩家本人（用户）的数值面板也一并抓取追踪（修为/等级/HP/属性/资源……） |
| 按人分档 | 剧情记忆按人物分档：和谁互动只注入谁，多人同场事件是「共有记忆」每人各存一份 |
| 生成前注入 | 每次生成前把「世界观 + 数值快照 + 当前活跃角色记忆 + 关联角色状态 + 全局大事件」注入 |
| 常驻世界观 | 每次注入优先带世界观（可自动拉取世界书常驻条目），历史被截断也不丢基础设定 |
| 改记忆 | 可视化面板直接改数值 / 删事件 / 改摘要 |
| 状态栏正则取数 | 每轮从正文状态栏正则抓精确数值，与 AI 总结双源校验，数值几乎不会错 |
| 关联人物注入 | 某角色活跃时自动带出其关联对象的状态（伴侣 / 宿敌 / 盟友……），可配置 |
| 主线大记忆 | 每次总结顺带提取「主线推进」，滚动压缩成宏观主线，始终注入 |
| 记忆导出/导入 | 面板一键导出/导入记忆 JSON，换设备、重装不丢 |

## 可调参数（设置面板里直接改）

- **总结楼层** `queueSize`（默认 5）：攒满约「此值 × 2」条消息自动总结一次；
- **每人事件窗** `eventsPerChar`（默认 15）：每个角色保留最近几条事件，滚出的压成该角色摘要；
- **全局大事件** `globalMax`（默认 20）：全局时间轴保留几条跨线大事件；
- **数值字段** `valueFields`：留空 = 自动识别；也可手动指定（一行一个 / 顿号分隔）；
- **角色名单** `charNames`：留空 = 自动识别；也可手动钉住；面板有「从世界书扫描人名」按钮；
- **关联人物** `relations`：格式 `角色A -> 角色B（关系说明）`，A 活跃时额外注入 B 的状态。

## 斜杠命令

| 命令 | 作用 |
| --- | --- |
| `/mem` | 查看记忆状态 + 数值快照 |
| `/mem-set 人物 字段 值` | 改数值，如 `/mem-set 沈清璃 好感 80` |
| `/mem-rm 人物` | 删除某人快照 |
| `/mem-sum [N]` | 手动总结最近 N 条消息（默认 3，范围 1-20）；面板也有「立即总结」按钮 |
| `/mem-clear` | 清空**当前角色卡**的全部记忆 |
| `/mem-clear-all` | 清空**所有角色卡/群聊**的记忆 |
| `/mem-scopes` | 列出已保存记忆的所有角色卡/群聊 |
| `/mem-export` | 导出**当前角色卡**记忆为 JSON（复制后可用面板「导入记忆」恢复） |

## 注意事项

- 总结调用你的**主 API**（`generateRaw` 后台生成，不显示在聊天里），会多花一点 token；嫌频繁就把 `queueSize` 调大。
- 总结失败会自动重试（最多 3 次），仍失败则跳过该批、不打断正常对话。
- 刷新页面或切换角色卡**不会**把旧消息重新总结一遍（已记录收集进度）。
- 记忆按**角色卡/群聊**隔离存储于酒馆 `extension_settings`，切卡不丢、换会话不丢；换酒馆实例需重新开始。
- 世界书常驻条目若已在 ST 里启用，本扩展会再注入一次作为「世界观·常驻」兜底（保证截断后仍在）；不需要可在面板关掉「自动拉取世界书常驻条目」。

## 故障排查

| 现象 | 排查 |
| --- | --- |
| 扩展列表里看不到 | 一键安装后记得**刷新页面**；手动安装要确认层级正确 |
| 不总结 | API 没连接；或按 F12 看控制台 `[story-memory]` 日志 |
| 总结乱码/没效果 | 主 API 输出 JSON 失败会自动跳过，属正常容错，不影响主对话 |
| 数值识别不对 | 在面板「数值字段」手动指定字段名；或确认正文状态栏格式是 `名字：字段 数值` |
| 想彻底停用 | 扩展列表取消勾选；`/mem-clear` 清当前卡、`/mem-clear-all` 清全部卡 |
